# サイドバーを常に出し、使っている間は行の位置を変えない

## 状況

herdr TUI では、サイドバーで、どのエージェントが自分を待っているかが一目で分かり、そこから移動できた。マウスでも操作したい。

## 決定

- サイドバーは常に出す。折りたたむと、自分を待っている数だけが残る帯になる。
- スペースを見出しにして、その下にターミナルを並べる。
- 並び順は、プラグインを起動したときの最終更新の新しい順にする。使っている間は並びを変えず、増えたものは一番上に入れる。
- 付けた名前は、ターミナルの label `herdr-core-nvim.name` に保存し、Neovim の中だけで使う。
- 色はテーマの色を混ぜて作り、ライトとダークで同じ決まりにする。

## 結果

得たもの:

- 折りたたんでも、自分を待っているエージェントがあることに気づける。
- 使っている間に行の位置が動かないので、マウスで押し間違えにくい。

失ったもの:

- 画面の幅を常に使う。
- Neovim で付けた名前は、Herdr アプリには出ない。

## 採らなかった案

- エージェントだけを 1 つの一覧にまとめ、待っているものを上に集める。状態が変わるたびに行が動く。
- 名前を Herdr アプリのタブ名（doc `herdr-app`）と同期する。アプリの内部仕様に依存し、アプリを使わないと名前を付けられない。
- hc のターミナル名を名前にする。hc には、起動したあとに名前を変える API がない。
- カーソル行をテーマの `Visual` や `Cursor` で示す。テーマごとの差が大きく、ノーマルモードのカーソルの色は端末が決めていて Neovim からは分からない。
