# サイドバーを常に出し、プロジェクトごとの木でターミナルを並べる

## 状況

herdr TUI では、サイドバーで、どのエージェントが自分を待っているかが一目で分かり、そこから移動できた。マウスでも操作したい。

## 決定

- サイドバーは常に出す。下端右端の `«` で折りたたむと、幅 2〜3 文字の帯になり、上に自分を待っている数（`blocked` と `done`）、下端右端に `»` が残る。
- ローカルのプロジェクトを見出しにして、その下にターミナルを並べる。ほかのマシンは、マシン名の見出しの下にプロジェクトをまとめる。つながらないマシンは、見出しに「接続なし」と出す。
- 見出しには、そのプロジェクトで自分を待っている数を出す。space は常に展開し、マシン見出しだけを折りたためる。
- ターミナルの行は 2 行にする。1 行目は状態の記号と色、名前（なければアドレス）。2 行目は前面のプログラム（`claude`、`pwsh` など）。

  ```
  herdr-session-transfer   ●1
    ● fix-login
      claude
      t3
      pwsh
  ```

- 並び順は、プラグインを起動したときの最終更新（`status_ms`、なければ `created_ms`）の新しい順にする。プロジェクトの更新は、中で一番新しいターミナルのもの。ピン留めしたものはプロジェクトの中で先に置く。使っている間は並びを変えず、増えたものは一番上に入れる。
- 操作:
  - ヘッダーの下の `New terminal` ボタン: Neovim のフォルダー、ホーム、このマシンの space から開く場所を選び、新しいターミナルを開く。選ぶ一覧は画面中央のフローティングウィンドウで、`setup` の `picker` で差し替えられる（`vim.ui.select` と同じ形）
  - `n`: その行の space の repo root で、新しいターミナルを開く
  - ターミナルの行で Enter かクリック: 開く
  - マシン見出しで Enter かクリック: 折りたたみを切り替える。space 見出しにはボタンがなく、`j`/`k` も止まらない
  - 名前を付ける、ピン留め、未読に戻す
- 見た目:
  - ボタン（`New terminal`、`«`/`»`、Setup の枠のボタン）は同じ背景にし、Enter でその行のボタンを押す。
  - 表示中のターミナルは灰色、それを含む space の見出しは反転、カーソル行は薄いアクセント色にする。ボタンのある行では、行には色を付けず、ボタンだけを濃いアクセント色にする。
  - 色はテーマの `Normal` と `DiagnosticInfo` を混ぜて作り、ライトとダークで同じ決まりにする。薄い文字はテーマの `Comment` を使わず、どの行の背景でも読める濃さにする。
- 付けた名前は、そのターミナルの label `herdr-core-nvim.name` に保存し、Neovim の中だけで使う。表示する名前は、この label、hc のターミナル名（`hc run --name`）、アドレスの順に選ぶ。バッファー名は変えない。
- サイドバーの中のキーには初期値を付け、設定で変えられるようにする。

## 結果

得たもの:

- 折りたたんでも、自分を待っているエージェントがあることに気づける。
- 使っている間に行の位置が動かないので、マウスで押し間違えにくい。

失ったもの:

- 画面の幅を常に使う。
- space ごとにターミナルを隠せないため、一覧が縦に長くなる。
- サイドバーからはターミナルを終了できない。ターミナルに入って `exit` する。
- マウスで space に新しいターミナルを開くには、`New terminal` を押して space を選ぶ 2 手がかかる。
- Neovim で付けた名前は、Herdr アプリには出ない。

## 採らなかった案

- 一覧はキーで開き、常に見えるのは件数だけにする。サイドバーを出したい。
- エージェントだけを 1 つの一覧にまとめ、待っているものを上に集める。状態が変わるたびに行が動く。
- 1 行に名前、プログラム、状態を並べる。横に長い。
- ダブルクリックで開く。手数が増える。
- 終了の操作を用意する。`exit` で足りる。
- 名前を Herdr アプリのタブ名（doc `herdr-app` の `spaces[].tabs[].name`）と同期する。doc にタブの項目ができるのはデスクトップアプリが取り込んだあとで、アプリを使わないと名前を付けられない。アプリの内部仕様に依存し、JSON を読んで書き戻すときに空の配列とオブジェクトの区別を失うおそれもある。デスクトップアプリを日常的に使うようになったら考える。
- hc のターミナル名を名前にする。hc には、起動したあとに名前を変える API がない。

- space を個別に折りたたむ。操作と状態を減らし、所属するターミナルを常に表示するため採らない。
- space の見出しの右端か、見出しの下の行に、space ごとの `+` ボタンを置く。space の数だけボタンが並ぶ。
- 開く場所を `vim.ui.select` で選ぶ。設定がない環境ではフローティングウィンドウにならず、サイドバーと見た目がそろわない。差し替え先としては使える。
- カーソル行をテーマの `Visual` や `Cursor` で示す。テーマごとの差が大きく、ノーマルモードのカーソルの色は端末が決めていて Neovim からは分からない。
