# 設定が必要なときだけ、サイドバーの下に Setup の枠を出す

## 状況

[integration](integrations.md) が入っていないと、再起動しても会話は戻らず、それに気づくのは再起動のあとになる。

## 決定

- 設定が必要な項目があるときだけ、サイドバーの下に Setup の枠を出し、そこから入れられるようにする。
- 枠は、Neovim を終了するまで隠せる。隠したことは保存しない。

## 結果

得たもの:

- 入れ忘れに、再起動の前に気づける。
- ターミナルの行と同じキーとマウスで操作できる。

失ったもの:

- 設定が必要な間は、サイドバーの下の場所を使う。
- 隠しても、起動のたびに出る。

## 採らなかった案

- 起動時にフローティングウィンドウで尋ねる。起動のたびにフォーカスを奪う。
- サイドバーの一番上に出す。ターミナルの行がずれる。
- 隠したことをずっと覚えておく。保存の場所と、もう一度出すコマンドが要る。
