# 設定が必要なときだけ、サイドバーの下に Setup の枠を出し、行を選んで入れる

## 状況

[integration](integrations.md) が入っていないと、再起動しても会話は戻らず、それに気づくのは再起動のあとになる。入れるときは、エージェントの設定ファイルを書き換える。

サイドバーは幅 32 文字で、ターミナルの行は使っている間に位置を変えない（[サイドバー](sidebar.md)）。

## 決定

- 設定が必要な項目があるときだけ、サイドバーの下、`«` の上に `Setup` の枠を出す。項目がなくなれば枠も消える。
- 項目は種類ごとの見出しの下に並べる。今の種類は `Integration` だけで、説明の行は `Supported agents detected.`。エージェントは、設定フォルダーがあれば検出したとみなす。

  ```
   ╭ Setup ─────────────────────╮
   │ Integration  Install all   │
   │ Supported agents detected. │
   │  claude      Install       │
   │  codex       Install       │
   │              Dismiss       │
   ╰────────────────────────────╯
                                 «
  ```

- 1 行に置くボタンは 1 つ。ボタンは左端をそろえ、名前との間を 1 文字以上空け、`[]` で囲まず背景色で示す。通常は space の見出しと同じ灰色、カーソルがある行ではアクセント色にする。
- 項目のボタンは、状態が `missing` なら `Install`、`outdated` なら `Update`。見出しのボタンは、項目が 2 つ以上のときだけ出す `Install all`。パネルの一番下に `Dismiss` を 1 つ置き、パネル全体を Neovim を終了するまで隠す。
- `j`/`k` はボタンのある行だけを移動する。`Enter` かクリックでその行のボタンを押す。
- 失敗した項目はボタンを `Retry` にし、下に `! 理由` の行を出す。
- 折りたたんだサイドバーには、待っている数の下に `!` を出す。

## 結果

得たもの:

- 入れ忘れに、再起動の前に気づける。
- ターミナルの行と同じキーとマウスで操作できる。
- 項目の種類が増えても、見出しを足すだけで済む。

失ったもの:

- 設定が必要な間は、サイドバーの下の場所を使う。
- `Dismiss` は保存しないので、起動のたびに出る。見出しごとには隠せない。
- ボタンの左端をそろえるので、項目の名前は 10 文字くらいまで。

## 採らなかった案

- 起動時にフローティングウィンドウで尋ねる。起動のたびにフォーカスを奪う。
- サイドバーの一番上に出す。ターミナルの行がずれる。
- 1 行だけ出し、選ぶと広がる。操作が 1 回増え、開閉の状態が要る。
- 検出したエージェントにまとめて入れるボタンだけにする。エージェントごとに選べない。
- 見出しごとに隠すボタン（`Not now`）を置く。項目が増えても、隠したいのはパネル全体。
- 実行するボタンと `Dismiss` で色を変える。状態が同じボタンは見た目を分けない。
- ボタンの右端をそろえる。左端がそろうほうが、どこを押せばいいか分かる。
- `Dismiss` をずっと覚えておく。保存の場所と、もう一度出すコマンドが要る。
- hc の `restore_screen` を項目にする。[再起動後の復元](restore-after-reboot.md)を参照。
