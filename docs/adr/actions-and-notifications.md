# 操作はアクションとして用意してキーは利用者が決め、通知は見ていないものだけを OS の通知で出す

## 状況

Claude Code や Codex は `Esc` を使う。done は「見ていない間に終わった」という印で、Herdr のクライアントとも共有する（`herdr.seen`）。

## 決定

- 操作をアクションとして用意し、グローバルなキーは割り当てない。利用者が設定で割り当てる。
- ターミナルのウィンドウに移ったら、自動でターミナルモードにする。抜けるキーは利用者が決め、プラグインは `Esc` を割り当てない。
- `blocked` と `done` になったら、OS の通知を出す。Neovim が前面にあり、そのターミナルが画面に表示されているときは出さない。
- done は、Neovim が前面にあり、そのターミナルが画面に表示されたら消す。

## 結果

得たもの:

- キーの割り当てが、利用者のほかの設定やエージェントのキーとぶつからない。
- Neovim が裏にあっても、待っているエージェントに気づける。誰も見ていない画面のせいで、ほかのクライアントの done が消えることもない。

失ったもの:

- 初期のキーの割り当てがないので、使い始める前に設定が要る。

## 採らなかった案

- 通知を Neovim の中だけにする。Neovim が裏にあると気づけない。
- done を、サイドバーで選んで開いたときだけ消す。表示しながら作業しているエージェントに、終わるたびに done が付く。
