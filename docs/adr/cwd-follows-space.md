# ターミナルが前面に来るたびに、Neovim の cwd をそのスペースに移す

## 状況

ターミナルは、スペース（リポジトリのルートか作業フォルダー）ごとに並んでいる。ターミナルからファイルを開くときや、ファイル検索、新しいターミナルの起動は、Neovim の cwd を起点にする。ターミナルを切り替えても cwd は変わらず、別のスペースのファイルを扱うたびに `:cd` が要った。

## 決定

- ターミナルが前面に来るたびに、Neovim の全体の cwd（`:cd`）をそのスペースに移す。
  - 移る先は、`herdr.space` ラベル、なければターミナルの `folder`。
  - 前面のターミナルが変わったときだけ移す。同じターミナルにいる間に、その中で `cd` しても追従しない。
  - cwd がすでにそこなら、何もしない。
  - 他のマシンのターミナルでは移さない。そのフォルダーはこのマシンにない。
  - フォルダーがこのマシンにないときは、何もしない。
- 既定で有効にする。`setup({ auto_cd = false })` で無効にできる。
- 判断は core が行う。ui/focus が前面のターミナルと全体の cwd を報告し、core が effect（`change_cwd`）を返し、app が `:cd` を実行する。

## 結果

得たもの:

- ターミナルを切り替えるだけで、ファイル検索や新しいターミナルの起点が、そのスペースになる。

失ったもの:

- 手で `:cd` しても、次に別のターミナルが前面に来ると上書きされる。
- 既存の利用者の cwd が、更新後に変わり始める。止めるには `auto_cd = false` が要る。
- `:lcd` や `:tcd` を設定したウィンドウやタブでは、そのウィンドウの cwd は変わらない。

## 採らなかった案

- タブごとの cwd（`:tcd`）。タブを移るたびに cwd が変わり、全体の cwd と食い違う。
- 前面のターミナルの中で `cd` したときにも追従する。ターミナルの中の移動で、ファイルのウィンドウの cwd まで動く。
- 既定で無効にする。ターミナルを切り替えて使う流れでは、有効のほうが手間が少ない。
