# 配置は hc の doc に保存し、複数の Neovim で同期して、起動時は常に復元する

## 状況

Neovim を閉じても、ターミナルは hc の core で動き続ける。開き直したときに、前と同じ並びで続きを使いたい。Neovim を複数開くこともある。

hc の core は、名前付きの JSON（doc）を版の番号付きで保存でき、変更を通知する。

## 決定

- タブページの並び、分割の形、どのウィンドウにどのターミナルを表示しているかを、hc の doc に保存する。
- 同じ core につないでいる Neovim は、すべて同じ配置を共有し、変更を互いに反映する。
- ファイルのウィンドウは同期しない。ターミナルとファイルが混ざったタブページは、ファイルのウィンドウを除いて同期する。
- Neovim を起動したら、起動のしかたに関係なく配置を復元する。
- ウィンドウを閉じても、ターミナルのプログラムは終了させない。

## 結果

得たもの:

- どの Neovim を開いても、同じ並びでエージェントが続きから使える。
- 配置の保存に、Neovim のセッションのプラグインが要らない。
- `:q` でうっかりエージェントを止めることがない。

失ったもの:

- `git commit` などで Neovim を開いたときも、配置が復元される。
- 同じタブページでも、Neovim ごとにファイルのウィンドウの有無が違う。

## 採らなかった案

- ファイルのウィンドウも同期する。同じファイルを 2 つの Neovim で開くと、スワップファイルの警告が出て、変更がぶつかる。
- ファイルを含むタブページは、その Neovim だけのものにする。ファイルを開いただけで、ほかの Neovim からタブページが消える。
- ウィンドウを閉じたらプログラムも終了させる（herdr と同じ）。うっかり止める危険が大きい。
