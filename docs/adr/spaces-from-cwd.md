# スペースは各ターミナルの今いるフォルダーの repo root で決め、Herdr のクライアントと label を共有する

## 状況

プロジェクトごとにエージェントやシェルをまとめたい。Neovim はほぼ `~` で起動し、タブを開いてから `cd` して `claude` を起動する、という使い方をしている。

Herdr のクライアントは、ターミナルの label で状態を共有している（[docs/labels.md](https://github.com/herdrdev/herdr-app/blob/5216e6f9f8c0c281a65e09816c66e4319e671784/docs/labels.md)）。`herdr.space` と `herdr.tab` を持つターミナルは、アプリのそのスペースとタブに表示される。

## 決定

- 各ターミナルのスペースは、そのターミナルの今いるフォルダー（hc の `foreground` の cwd）の git の repo root にする。git でなければ、そのフォルダーにする。`cd` するたびに決め直す。
- スペースはターミナルごとに決める。同じタブページに、別のスペースのターミナルが並んでもよい。
- スペース、タブ、既読、ピン留めは、Herdr のクライアントと同じ label（`herdr.space`、`herdr.tab`、`herdr.seen`、`herdr.pinned`）に書く。

## 結果

得たもの:

- いつもの流れ（`cd` → `claude`）のままで、エージェントがプロジェクトごとに分かれる。エージェントのプロセス名の一覧を持たなくてよい。
- スマートフォンアプリからも、同じエージェントをプロジェクトごとに見て操作できる。

失ったもの:

- シェルで `cd` するたびに、そのターミナルのスペースが変わる。
- Neovim のタブページと分割の形は、アプリには出ない。

## 採らなかった案

- スペースをターミナルの起動時に決めて固定する。`~` で開いてから `cd` するので、エージェントがすべて `~` に入る。
- エージェントの起動だけを検出して、スペースを決める。プロセス名の一覧が要る。
- プラグインのコマンドでエージェントを起動し、そのときに label を付ける。シェルで `claude` と打つ使い方ができなくなる。
- アプリの配置（doc `herdr-app`）も読み書きする。アプリの内部仕様に依存し、アプリの状態を壊すおそれがある。
