# core/setup.lua

The Setup panel's state and rows.

- [x] When integrations need setting up, `view` can show them under one heading with Install all, the note, one button each and Dismiss at the bottom.
- [x] When only one integration is left, `view` can leave Install all out and keep Dismiss at the bottom.
- [x] When the user installs one or all, `update` can ask to install those names.
- [x] When an install fails or succeeds, `view` can offer Retry with the reason or hide the finished item.
