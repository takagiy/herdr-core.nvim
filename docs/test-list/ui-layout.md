# ui/layout.lua

Tabpages and windows in Neovim.

- [ ] When asked to show a layout, Neovim can get its tabpages and splits with each window showing its terminal.
- [ ] When asked to show a new layout, Neovim can keep the current tabpage and window focused if they still exist.
- [ ] When asked to show a new layout, Neovim can keep the file windows that were open.
- [ ] When the user splits, closes or moves a terminal window or tabpage, the change can be reported as the arrangement of terminal windows.
- [ ] When the arrangement is reported, the sidebar and file windows can be left out of it.
